## 3. Задание для самостоятельной работы
Написана программа `lab6-4.asm` для вычисления выражения варианта № 5: f(x) = (9x - 8)/8.
- При x1 = 8 результат равен **8**.
- При x2 = 64 результат равен **71**.

```nasm
%include 'in_out.asm'

SECTION .data
expr: DB 'Вычисление выражения f(x) = (9x - 8)/8',0
msg:  DB 'Введите значение x: ',0
res:  DB 'Результат: ',0

SECTION .bss
x: RESB 80

SECTION .text
GLOBAL _start
_start:
    mov eax, expr
    call sprintLF
    mov eax, msg
    call sprint
    mov ecx, x
    mov edx, 80
    call sread
    mov eax, x
    call atoi
    mov ebx, 9
    mul ebx
    sub eax, 8
    xor edx, edx
    mov ebx, 8
    div ebx
    mov edi, eax
    mov eax, res
    call sprint
    mov eax, edi
    call iprintLF
    call quit
```

## 4. Ответы на вопросы для самопроверки
1. Синтаксис сложения: `add <приёмник>, <источник>`.
2. Умножение без знака: `mul <операнд>`.
3. Деление без знака: `div <делитель>`.
4. При умножении двухбайтовых операндов результат помещается в пару регистров `DX:AX`.
5. Целочисленные арифметические команды: `add`, `sub`, `mul`/`imul`, `div`/`idiv`, `inc`, `dec`, `neg`.
6. Делимое находится в `AX` (1 байт), `DX:AX` (2 байта) или `EDX:EAX` (4 байта).
7. Частное помещается в `AL`/`AX`/`EAX`, а остаток — в `AH`/`DX`/`EDX`.
